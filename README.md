白盒代码审计技能集（White-box Code Audit Skills）

## 安装

方式一（Hermes CLI）：

```bash
hermes skills install <技能目录路径>
```

方式二（手动）：将技能目录复制到 Hermes skills 目录（如 `~/AppData/Local/hermes/skills/pentest/`），开新会话生效。
